Hospital Operations & Patient Flow Dashboard (Power BI)
Project Overview

This project presents an interactive Power BI dashboard developed to analyze hospital patient activity, operational performance, clinical case characteristics, and revenue patterns.

The dashboard provides a high-level view of patient volume, length of stay, case severity, specialty activity, payer contribution, and revenue to support data-driven hospital management and further investigation.
